# CYP Challenge

Решение OpenADMET CYP Inhibition Blind Challenge: предсказание ингибирования CYP1A2, CYP2C9,
CYP2D6 и CYP3A4 по структуре молекулы. Отправка закрывается 3 ноября 2026.

Главный документ — [`docs/CYP — модель и данные.pdf`](docs/). Тридцать страниц: биохимия задачи,
что лежит в данных и что мы из них измерили, устройство модели с обоснованием каждого элемента,
протокол проверки, список того, что уже проверено и не работает. Всё остальное в репозитории —
код, которым эти числа получены.

## С чего начать

```bash
pip install -r requirements.txt
bash data/fetch.sh          # скачать данные соревнования (~7 МБ)
python src/feats.py         # признаки: фингерпринт, дескрипторы, механистический блок
python src/base.py          # базовая линия, макро ST-RAE ≈ 0.773
```

## Пайплайн

Порядок такой, каждый шаг зависит от предыдущего:

1. `src/feats.py` — строит `data/feats.npz`: счётчики Моргана r=2 (2048), 217 дескрипторов RDKit,
   28 механистических признаков. Механистический блок использует `src/pka.py` — правило оценки
   pKa самого основного центра.
2. `src/base.py` — базовая линия на фингерпринте с дескрипторами, пятикратная кросс-валидация
   по кластерам Бутины при пороге 0.35.
3. `src/ablate.py` — шесть наборов признаков на тех же фолдах, сохраняет out-of-fold предсказания
   в `results/preds/oof.json`.
4. `src/score.py` — метрики и парный бутстрап по сохранённым предсказаниям.
5. `src/range.py`, `src/rangectl.py` — проверка ограничения диапазона на CYP2D6.
6. `src/mech2.py`—`src/mech4.py` — три способа подключить первичный скрининг, все три отрицательные.
7. `src/tdibase.py`, `src/tdiprob.py` — базовые линии классификационного трека.
8. `src/decision.py`, `src/decision2.py` — решающий слой под ST-RAE и его оракульный потолок.

## Ключевые числа

Пятикратная кросс-валидация по кластерам Бутины, порог 0.35, зерно 0.

| | 1A2 | 2C9 | 2D6 | 3A4 | Макро |
|---|---|---|---|---|---|
| ST-RAE, фингерпринт и дескрипторы | 0.880 | 0.702 | 0.993 | 0.518 | 0.773 |
| ST-RAE, плюс механистический блок | 0.879 | 0.691 | 0.980 | 0.519 | 0.767 |
| Спирмен, плюс механистический блок | 0.496 | 0.597 | 0.403 | 0.765 | 0.565 |
| Ско ST-RAE по четырём зёрнам разбиения | 0.0109 | 0.0078 | 0.0052 | 0.0057 | 0.0019 |

Единица по ST-RAE — это предсказание одного числа для всех соединений. CYP2D6 стоит почти на ней,
и разбор причин занимает третий раздел документа.

## Правила работы

Всё это выведено из измерений, а не из общих соображений; обоснование в документе.

- Сравнивать варианты только на одном и том же разбиении и только с парным бутстрапом
  по соединениям. Разность без интервала не является результатом.
- Одного разбиения мало: смена зерна двигает макро ST-RAE на 0.016, что больше типичного
  измеряемого эффекта. Любое решение о том, что отправлять, принимается минимум по четырём зёрнам.
- Наша кросс-валидация труднее настоящего теста на 0.153 по медианному сходству с ближайшим
  обучающим соединением. Локальные числа — оценка снизу, но и отбирают они не то умение,
  за которое платит лидерборд.
- Отрицательные результаты фиксируются и остаются в репозитории. Их уже четыре.
