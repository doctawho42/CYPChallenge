# Данные

В git не хранятся: это опубликованные файлы соревнования, они и так доступны, а вместе
занимают около семи мегабайт.

```bash
bash data/fetch.sh
```

После этого здесь должно лежать пять файлов.

| Файл | Строк | Что это |
|---|---|---|
| `cyp-challenge-TRAIN_inhibition.csv` | 4905 | pIC50 прямого ингибирования, границы интервала, стандартная ошибка |
| `cyp-challenge-TRAIN_TDI.csv` | 6145 | то же для условия с преинкубацией плюс метки TDI |
| `cyp-challenge-TRAIN_Emax.csv` | 6146 | предельная глубина подавления, оба плеча |
| `cyp-challenge-single-concentration-TRAIN.csv` | 17504 | одноточечный скрининг при 49.5 мкМ |
| `cyp-challenge-TEST-BLINDED.csv` | 750 | тест, только имя и SMILES |

Производные файлы (`feats.npz`, `rows.csv`) строит `src/feats.py`, они тоже не коммитятся.
Сохранённые out-of-fold предсказания лежат в `results/preds/` — их пересчёт занимает около часа,
поэтому они в репозитории есть.
