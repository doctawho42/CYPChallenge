# Исходники документа

`main.tex` подключает `preamble.tex` и разделы `s01`…`s14` по порядку. Сборка — `../build.sh`
или три прогона `xelatex main.tex`.

Графики строит `figs.py` в `fig/` сразу в pdf и png, в натуральную величину страницы:
полосу текста 6.1 дюйма занимают графики шириной ровно 6.10, так что подписи не масштабируются
при вставке и стоят в том же кегле, что основной текст. Цвет закреплён за ферментом во всех
графиках: 1A2 синий, 2C9 кирпичный, 2D6 зелёный, 3A4 охра. Палитра проверена на различимость
при дальтонизме и на контраст с фоном.

| Раздел | Тема |
|---|---|
| `s01` | задача и обе метрики |
| `s015` | биохимия: P450, IC50, TDI, чем различаются четыре фермента |

| `s03` | базовая линия и три версии провала на CYP2D6 |
| `s04` | порождающая модель, правдоподобия, калибровка прибора |
| `s05` | идентифицируемость, крутизна и глубина кривой |
| `s06` | механизм пропусков и разложение совместного распределения |
| `s07` | архитектура, коррегионализация, механистический блок |
| `s08` | функция потерь и обучение |
| `s09` | неопределённость |
| `s10` | решающий слой для обеих метрик |
| `s11` | трансдуктивный слой |
| `s12` | протокол оценки, устойчивость к разбиению |
| `s13` | что уже измерено и не работает |
| `s14` | ожидаемые провалы, непроверенное, сводка чисел |
