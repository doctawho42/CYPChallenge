## Правила, которые держат этот журнал

1. Выигрыш считается только ПОСЛЕ пер-фолдовой аффинной пары; всё цитируется против пола
   (макро ранг 0.0036; пер-ферментно 0.0061/0.0071/0.0049/0.0033; ST-RAE 0.007; MCC 0.0281/0.0419).
2. Знак считается по сидам, минимум два, для отгрузки четыре. Золотой дайджест сида 0 —
   `2d93c19815e14261`; пять членов на нём дают ранг **0.6434** — это контроль воспроизводимости,
   он есть в k132/k134/k135/k139/k140.
3. Предсказания выносятся в `docs/transfer_axis.md` и коммитятся ДО запуска. Это окупилось:
   пункт 364 поймал трёхсотпунктовое допущение только потому, что P5–P8 были выписаны заранее.
4. Контроль, который не может провалиться, — не контроль (пункт 319). Каждый новый контроль
   проверяется на том, что он падает на неверных данных.
5. Шестой слот стоит примерно на 0.006 ранга больше седьмого (п. 361) — кандидаты, добавленные
   при разном числе членов, несравнимы.
