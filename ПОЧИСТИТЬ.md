# Разовая уборка после переноса

Репозиторий собран из облачной сессии, у которой не было прав на удаление файлов
в этой папке. Поэтому мусор сложен в `_to_delete/`, а не удалён. Удалите его руками:

```bash
cd "$(dirname "$0")"
rm -rf _to_delete
rm -f .git/*.lock .git/objects/*.lock
find .git/objects -name 'tmp_obj_*' -delete
git gc --prune=now
rm ПОЧИСТИТЬ.md
```

Что там лежит:

- `_repo.tar.gz` — архив, из которого всё распаковано;
- `CYPChallenge/` — вложенная копия того же дерева, оставшаяся после распаковки;
- `locks/` — файлы блокировок git, которые не удалось убрать;
- `index.lock.old` — то же самое.

Плюс в `.git/objects/` осели временные файлы `tmp_obj_*`: git записал объекты, но
не смог подчистить за собой. На целостность они не влияют, `git fsck` проходит,
но `git gc --prune=now` их уберёт.

Пока `_to_delete/` не удалён, обычные команды git работают, но каждая читающая
команда оставляет новый `.git/index.lock`. Если следующий коммит скажет
«Another git process seems to be running» — просто удалите этот файл.
